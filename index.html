    Medical image classifier

    Diabetic Retinopathy Detection

    Flags diabetic retinopathy in retinal fundus photographs. An OpenCV pipeline (circular crop, Gaussian blur, CLAHE) feeds a MobileNetV2 transfer-learning model, and Grad-CAM heatmaps show which regions drove each prediction. It reaches 91.8% accuracy and 0.97 ROC-AUC on 293 held-out APTOS 2019 images, and runs as a Streamlit app.

    • Python
    • TensorFlow
    • OpenCV
    • Streamlit
